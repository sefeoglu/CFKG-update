# Shot Selection for Few-Shot Learning based on Active Learning

## Sampling Methods
- **Random Sampling**: Selects samples randomly from the dataset.
- **KMeans Sampling**: Uses KMeans clustering to select samples that are representative of the dataset.
- **KMeans Sampling with KNN**: Similar to KMeans but uses KNN to select samples based on their distance to the cluster centroids.
- **Gaussian Mixture Model Sampling**: Uses a Gaussian Mixture Model to select samples based on their probability density.
